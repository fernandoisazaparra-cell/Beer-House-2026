# Beer-House-2026
"Beer House es un aplicativo web para una licorera de Medellín que hoy gestiona ventas, inventario y pedidos de forma manual, generando pérdida de información y reprocesos. El proyecto la digitaliza con ventas online, pagos seguros, catálogo e inventario en tiempo real, roles de usuario, historial de compras y reportes para la toma de decisiones."
